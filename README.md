# Fenix Comercio Exterior

Sitio web institucional desarrollado para **Fenix Comercio Exterior**, empresa dedicada a operaciones de comercio internacional, importación, exportación, logística internacional y asesoramiento documental.

El objetivo del sitio es presentar una imagen profesional, clara y confiable de la empresa, mostrando sus servicios, proceso de trabajo, novedades del sector y canales de contacto.

## Contenido del sitio

- Página principal institucional.
- Servicios destacados.
- Página completa de servicios.
- Proceso de trabajo.
- Información sobre la empresa.
- Novedades del sector.
- Artículos informativos.
- Formulario de contacto.
- Footer con enlaces y datos de contacto.

## Tecnologías utilizadas

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel
